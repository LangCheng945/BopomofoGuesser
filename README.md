# 注音猜猜樂 | Bopomofo Guesser

## 中文 🇹🇼

注音猜猜樂是一個使用 HTML、CSS 和 JavaScript 製作的小遊戲，靈感來自台灣常見的注音符號（ㄅㄆㄇㄈ）。

遊戲規則很簡單，每次開始時，系統會從 37 個注音符號中隨機選出一個作為答案。玩家只需要點擊畫面上的注音符號進行猜測，猜錯的選項會變成灰色，直到找到正確答案為止。

遊戲會記錄猜測次數，猜對後也可以把結果複製下來分享給朋友，看看誰能用最少的次數猜中。

這個專案沒有使用任何前端框架，只有原生 HTML、CSS 和 JavaScript，不需要登入或安裝任何東西，打開網頁就能直接玩。

## English 🇺🇸

Bopomofo Guesser is a small browser-based guessing game built with HTML, CSS, and JavaScript, based on the Zhuyin (Bopomofo) phonetic system used in Taiwan.

The rules are pretty simple. Each round, the game randomly picks one of the 37 Bopomofo symbols, and your goal is to figure out which one it is.

Just click on the symbols to make your guesses. Incorrect choices will turn gray, so you won't accidentally pick the same one again. The game keeps track of your attempts, and once you find the correct answer, you can copy and share your results with friends.

The whole project is written in plain HTML, CSS, and JavaScript without any frameworks or external dependencies. There's no account or installation required. Just open the website and start guessing.
